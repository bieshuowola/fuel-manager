# 「骑行」系统快捷开关（0.2.0）

这是 Android 官方 TileService，不是仿控制中心页面。标签始终为「骑行」，单色摩托车图标取自 Google Material Icons `two_wheeler`（Apache-2.0）。不修改网页版或主页布局。

## 添加和使用

1. 安装 0.2.0 Debug APK，可覆盖同签名 0.1.0（versionCode 由 1 升为 2，包名和测试签名不变）。先保留燃油 JSON 备份。
2. 下拉系统控制中心／快捷设置，进入编辑，将「骑行」拖入常用区域。也可点击燃油管家原页面左上油泵图标，在原生菜单选择“添加骑行快捷开关”；Android 13+ 尝试系统添加对话框。OriginOS 的入口、第三方磁贴排列及是否允许添加须在 vivo 实机确认，应用不能越过 OEM 限制。
3. 仅在骑自己的摩托车时点击开启。第一次说明用途并分别请求精确定位、通知；定位关闭时可转到系统定位设置。拒绝时不开启，原油表仍可手动使用。
4. Android 14–16 使用系统 `startActivityAndCollapse(PendingIntent)`，经过短暂可见的原生启动页合法创建定位前台服务，成功后返回，不加载 WebView 主界面。已有权限时无需进入主页面操作。锁定时先请求系统解锁；系统拒绝启动则保持关闭并提示。
5. 定位订阅实际建立后才高亮。再次点击会保存当前有效行程、结束会话、注销定位请求并移除持续通知。暂停时显示未激活，点按结束暂停会话；可在持续通知中继续。高亮表示正在采集，不表示 GPS 覆盖或油量估算已被证明可靠。
6. 长按通过官方 `ACTION_QS_TILE_PREFERENCES` 进入原燃油主页；部分 OriginOS 版本可能按自己的规则进入设置，需实机确认。

仍保留活动识别作为防忘提醒。IN_VEHICLE 本身不开始本车记账，汽车和公交不用开启磁贴。未确认行程继续隔离。GPS、真实 ODO、燃油模型和旧 JSON 格式不变。

## 状态与安全

磁贴以活的定位服务、精确权限、定位提供者和已建立的订阅为依据，不会仅凭磁贴 UI 或磁盘 `active=true` 高亮。服务在开始、暂停、继续、结束、错误、销毁及重启恢复时请求系统刷新；控制中心重新可见也会核对状态。后台进程不存在时，持久化未结束的行程只关闭一次，保留有效公里和中断标记，要求 ODO 校准，不自动补零或悄悄重启 GPS。

同进程主线程上的请求 token 合并重复开始、取消尚未确认的开启、拒绝延迟的旧命令；旧服务销毁不会取消更新的点击。停止仍可由持续通知或原生菜单发起。过期“继续”通知不能重启已结束行程。定位订阅失败或权限撤销后不保留虚假运行状态。

红灯和短停不结束会话；通过距离过滤器的缓慢拥堵位移也会延续行程。持续有效静止证据达到 10 分钟才按原状态机结束；自动结束会同步通知和磁贴。无定位不等于静止：45 秒无可靠点降低可信度，5 分钟持续中断停止并要求 ODO 校准。未知区间仍由原有安全策略暂停可信油量数值。

## 本次验收范围

Robolectric/API 35 验证系统组件注册、权限保护、严格标签和图标、长按入口解析、默认关闭、真实订阅后高亮、停止保存一次、连续点击取消、延迟命令、重复启动单订阅、暂停/继续约束、权限拒绝与撤销、系统拒绝前台服务、定位关闭、进程/重启中断、自动结束、旧服务销毁竞态，以及独立原生启动入口不加载 WebView。

这些是 JVM 平台模拟测试，不是 vivo X100 / Android 16 真机通过。必须在真机完成：磁贴添加与排序、图标显示和高亮、锁定解锁取消、首次权限拒绝/近似定位、连续点击、切后台/锁屏/熄屏长骑、定位开关、权限撤销、清理进程、手机重启、10 分钟停车自动结束及长按入口。确认应用服务停止后系统定位指示消失，恢复后无双重里程。真实误差、耗电和 OriginOS 后台保活仍按 DEVICE_ACCEPTANCE.md 验证。

## 下载方式

交付前 `scripts/verify_apk.py` 检查 APK 内真实版本、TileService 权限/动作、DEX 类、标签「骑行」、当前网页资源、签名和 ZIP 对齐，再生成纯 ASCII 名称 `fuel-manager-0.2.0-debug.apk` 和 SHA256 文件。通过构建后的 GitHub 测试 Release 提供单独 `.apk` 直链，不需要 ZIP 或手动解压；Actions Artifact 保留为备用。

当前 Codex 工具没有上传／附加文件能力，运行环境也明确共享路径不自动成为对话附件，因此不能将 `/workspace/...` 或虚构 `sandbox:` 链接冒充手机下载附件。最终报告会给经过实际下载核验的 HTTPS APK 链接并说明该限制。
